
# Loan Approval & Risk Analysis Using PostgreSQL

##  Project Overview

Analysis of **30,000 loan applications** using PostgreSQL to understand loan approval, credit risk, financial health, and interest-rate patterns.

##  Objective

* Analyze loan approval patterns.
* Identify factors affecting approval and default risk.
* Generate business insights using SQL.

##  Tools

* PostgreSQL
* SQL
* GitHub

##  Analysis

* Data Cleaning & Validation
* Loan Portfolio Analysis
* Customer Profile Analysis
* Approval Analysis
* Credit Risk Analysis
* Financial Health Analysis
* Regional & Channel Analysis
* Collateral & Co-applicant Analysis
* Interest Rate Analysis

##  Key Results

* Higher credit scores → higher approval rates
* Higher income → better approval outcomes
* Lower DTI → higher approval rates
* Better repayment history → higher approval
* Higher risk → higher interest rates
* Collateral-backed applications → higher approval rates

**Detailed findings:** [`insights/key_findings.md`](insights/key_findings.md)

##  Suggestions

* Strengthen credit-risk assessment.
* Monitor high-DTI and high-risk applicants.
* Consider collateral during risk evaluation.
* Use risk-based pricing.
* Build a predictive loan-risk model in the future.
